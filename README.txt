NEBULA - Godot 4.7.x mobile-friendly sci-fi platformer

PROJECT
- Main scene: scenes/main.tscn
- Main gameplay script: scripts/main.gd
- Landscape 1280x720 project viewport.
- Visuals are drawn by GDScript; no external art assets are required.

GAMEPLAY
- Move through the neon industrial sector.
- Collect glowing energy cells.
- Avoid floor spikes and patrolling security drones.
- Reach the green checkpoint, then find the exit portal.
- You have 3 health points. Damage sends you back to the last checkpoint.
- The level can be restarted after victory or game over.

CONTROLS
- Keyboard: A/D or Left/Right to move; Space/W/Up to jump; P or Escape to pause; R to restart after the end.
- Touch: use the two lower-left controls to move and the lower-right control to jump.
- Tap the pause icon at the upper-right corner.

IMPORT
1. Extract the ZIP or download the repository.
2. In Godot Project Manager, choose Import.
3. Select project.godot in this folder.
4. Open the project. The game has not been runtime-tested as part of this source update.
