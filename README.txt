NEBULA - Fixed starter project for Godot 4.7.x Android Editor

1. Extract this ZIP.
2. In Godot Project Manager choose Import.
3. Select project.godot inside the NEBULA folder.
4. Open and run the project.

Touch: left half of screen moves (left quarter = left, second quarter = right); tap right half to jump.
Keyboard: A/D or arrows to move, Space/W/Up to jump.

This is a prototype using code-drawn placeholder visuals. Renderer selection is not overridden.
